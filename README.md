# 🕊️ Sitio Web Oficial - Ángeles de Esperanza, A.C.

## 📖 Descripción del Proyecto
Este repositorio contiene el código fuente del sitio web oficial de **Ángeles de Esperanza, A.C.** (https://www.angelesdeesperanzaac.org)[cite: 9]. El proyecto web está diseñado para comunicar de manera empática y profesional los servicios de este centro de rehabilitación de adicciones, ubicado en Irapuato, Guanajuato[cite: 9]. 

El diseño y contenido están enfocados en informar a prospectos y familiares sobre el modelo de tratamiento residencial voluntario de 6 meses dirigido a población varonil de 18 a 50 años[cite: 9].

## 🗺️ Arquitectura del Sitio
El sitio está estructurado para guiar al usuario desde el impacto emocional hasta la conversión (contacto), abarcando:
* **Inicio (Landing Page):** Resumen de servicios, acreditaciones oficiales y llamados a la acción inmediatos.
* **Quiénes Somos:** Historia fundacional, filosofía (misión, visión y valores) y marco legal[cite: 9].
* **Modelo de Recuperación:** Detalle del enfoque clínico basado en el modelo de Prochaska y DiClemente, nutrición clínica, acondicionamiento físico, educación y el programa de 12 pasos[cite: 9].
* **Equipo Multidisciplinario:** Perfiles profesionales del área directiva, médica, psicológica y de consejería[cite: 8, 9].
* **Galerías y Blog:** Recursos visuales de las instalaciones, testimonios y artículos de apoyo familiar.
* **Contacto:** Integración de Google Maps, números de emergencia, WhatsApp y formularios de ayuda.

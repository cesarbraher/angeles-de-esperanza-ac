# Ángeles de Esperanza A.C. - Sitio Web

Esta es la estructura completa del sitio.
- **index.html**: Landing page principal.
- **styles.css**: Estilos globales.
- **script.js**: Lógica del menú móvil y API del blog.
- **enviar.php**: Script procesador del formulario de contacto.
- **pages/**: Subpáginas con la extensión de información de cada área.
- **assets/img/**: Directorio donde debes subir "LOGOTIPO TRANSPARENTE.png" y reemplazar los placeholders.
- **assets/videos/**: Directorio para tu video `video-certificaciones.mp4`.
